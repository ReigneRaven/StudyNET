# StudyNET

StudyNET is an application designed to help users review and strengthen their understanding of networking concepts. It provides structured study materials on key topics along with interactive quizzes to assess knowledge and reinforce learning.

To ensure a smooth and intuitive user experience, the application flow and interface were designed using Figma. The interactive prototype illustrates the overall navigation, screen flow, and user journey of the application. Below is the link to view the Figma design and application flow:
